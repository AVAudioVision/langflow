:::tip
Install this provider from the long-tail metapackage:

```bash
uv pip install "lfx-bundles[<bundle>]"
```

Replace `<bundle>` with this page's provider name, for example `qdrant`.
To install every long-tail provider at once, run `uv pip install "lfx[bundles]"`.
See the [Bundle list](./extensions-bundle-list) for the exact extra name.

Long-tail bundle components are not included by default with `uv pip install langflow`.
:::
